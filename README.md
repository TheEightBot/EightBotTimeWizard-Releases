# EightBot Time Wizard — releases

Signed installers and update files for EightBot Time Wizard, the EightBot team's desktop time assistant. Source code is private.

This repository holds release assets only:

- Windows and macOS installers and the Velopack update feed, attached to each [release](../../releases)
- The plugin index and signed plugin packages

## Install

Team members: follow the onboarding guide shared internally. Windows installs need the EightBot signing certificate, which the enrollment script trusts for you.
